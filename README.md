# 2025-2TeamProject
2025년 2학기 게임프로젝트 실무, 김종우(기획), 권민혁(프로그래밍), 진현우(그래픽)  
**유니티 버전**: 2022.3.62f1, 3D URP

> **⚠️ 설계 초안 문서**  
> 이 문서는 Claude Code에게 제공될 게임 설계 초안입니다.  
> 실제 구현 과정에서 세부사항은 변경될 수 있습니다.

## 게임 개요
6x6 그리드 기반의 전략적 카드 배틀 게임으로, 플레이어가 카드를 사용하여 유닛을 소환하고 적 기지를 파괴하는 것이 목표입니다.

## 핵심 게임플레이
- **그리드 시스템**: 6x6 보드에서 진행되는 전술적 전투
- **카드 시스템**: Pawn(유닛 소환) 카드와 Spell(즉시 효과) 카드
- **턴 기반 전투**: Enemy Turn → Player Turn → Between Phase 순서로 진행
- **자동 전투**: Between Phase에서 모든 유닛이 자동으로 행동

## 개발 단계별 계획

### Phase 1: 코어 아키텍처 및 게임플레이 루프 (설계 초안)
**목표**: 게임의 기본 흐름과 확장 가능한 아키텍처 구축

#### 핵심 데이터 구조
- **UnitStats**: 유닛의 모든 능력치 관리 (체력, 공격력, 이동거리)
- **IDamageable**: 피해를 받을 수 있는 객체들의 공통 인터페이스

#### 데이터 기반 설계
- **UnitData (ScriptableObject)**: 유닛 타입별 원본 데이터 정의
- **CardData (ScriptableObject)**: 카드별 데이터 및 효과 정의

#### 게임 로직 계층
- **Entity (추상 클래스)**: 모든 게임 오브젝트의 공통 부모
- **Pawn**: 필드에서 움직이는 기본 유닛
- **Base**: 플레이어 기지 (파괴 시 게임 오버)

#### 핵심 시스템
- **GridManager**: 6x6 보드 상태 관리 및 유닛 배치 규칙 통제
- **TurnManager**: 게임 흐름 제어하는 상태 머신
  - Enemy Turn: 적 카드 사용 단계
  - Player Turn: 플레이어 카드 사용 단계  
  - Between Phase: 모든 유닛의 자동 행동 단계

#### 플레이어 인터페이스
- 카드 클릭 → 타일 선택 → 유닛 소환/효과 발동
- 턴 종료 버튼으로 단계 전환
